# Hello World Web App - Flask Demo

Aplicación web simple desplegada en Render. Proyecto demo para mostrar habilidades con Python, Flask y despliegue en la nube.

## 🌐 Demo en vivo

👉 [https://tkinter-hello-demo.onrender.com](https://tkinter-hello-demo.onrender.com)

## 📋 Tecnologías

- Python 3.12
- Flask 3.1.3
- Gunicorn (servidor de producción)
- HTML/CSS/JavaScript

## 🚀 Características

- ✅ Interfaz web responsive
- ✅ Botón interactivo con JavaScript
- ✅ Código limpio y comentado
- ✅ Desplegado en la nube con Render

## 🛠️ Ejecutar localmente

```bash
# Clonar el repositorio
git clone https://github.com/edgardotal/tkinter-hello-demo

# Entrar a la carpeta
cd tkinter-hello-demo

# Instalar dependencias
pip install -r requirements.txt

# Correr la app
python app.py
Abrir http://localhost:5000 en el navegador.

📁 Estructura del proyecto
text


# Hello World Web App

Aplicación web que muestra "Hello, World" con un botón Exit.

## Tecnologías

- Python 3
- Flask
- HTML/CSS/JS

## Ejecutar local

```bash
pip install -r requirements.txt
python app.py
```

Abrir http://localhost:5000

## Despliegue

Esta app está lista para desplegar en Render, PythonAnywhere o Railway.
